# 三峽白雞觀光商場 官網 — 總覽與目標

> 狀態：**架構確認 v0.4**　最後更新：2026-10-02
> 本輪討論的網站架構（Sitemap、導覽、頁面互動模式）已確認。各頁面內部的詳細內容（文案、版型細節）將另開新 session 討論，屆時再回頭更新本資料夾文件。

## 1. 專案背景

網站主體為「三峽白雞觀光商場」，核心任務是讓還沒到過現場的遊客，能在到訪前就解決三個問題：
**怎麼去、商場裡有什麼（含必要設施）、逛完商場還能去哪裡**。商場本身的店家資料目前尚未齊備，因此店家相關頁面先建立結構與樣板，內容等商場管理方日後提供。

## 2. 目標受眾

| 受眾 | 主要需求 | 對應內容 |
|---|---|---|
| 自駕遊客 | 路線、停車 | 交通方式、商場介紹（停車場） |
| 登山客 | 步道資訊、安全須知 | 登山資訊 → 白三山步道 / 白雞山-紫微天后宮步道 |
| 信眾 / 參拜遊客 | 行脩宮資訊、參拜須知 | 周邊景點 → 行脩宮 ↗（外部連結至官網 https://www.ht.org.tw/，站內不重複維護內容） |
| 親子 / 一般遊覽團體 | 設施（廁所、無障礙、休憩） | 商場介紹 |
| 想順遊三峽的遊客 | 周邊景點串聯建議 | 周邊景點 → 周邊三峽景點 |

## 3. 內容五大支柱

1. **交通方式** — 自駕 / 大眾運輸 / 停車，解決「怎麼去」。頁面內以頁籤拆成「開車」「大眾運輸」，同一路由。
2. **商場店家**（先建結構） — 分類列表＋Popup 詳情（不另開路由），資料待補。
3. **周邊景點** — header 下拉選單：行脩宮 ↗（外部連結，站內不設頁面）、周邊三峽景點（站內子頁），解決「逛完去哪（文化／順遊景點）」。
4. **登山資訊**（獨立於周邊景點之外） — 列表＋Popup 詳情（不另開路由），白三山登山步道、白雞山-紫微天后宮步道，解決「逛完去哪（登山健行）」。
5. **商場介紹** — 商場簡介＋必要設施（停車、廁所、無障礙、休憩、服務台等），解決「商場裡有什麼」。放在主選單**最右側**，以對比色／加粗呈現，方便使用者第一眼就找到。

**精簡原則**：最新消息／活動公告不獨立開頁，併入首頁呈現；關於我們／聯絡資訊也不獨立開頁，相關資訊（目前僅 Email）併入頁尾（Footer）。這兩項待內容更完整後再評估是否需要獨立頁面。

## 4. 本階段範圍（Scope）

**這階段要做：**
- 完整網站架構（Sitemap）與頁面內容規格
- 首頁作為獨立頁面，含輪播圖／最新訊息／店家工商廣告三區塊；Header 左側 Logo 為全站回首頁的連結
- 商場店家的頁面結構與元件樣板（無真實資料）
- 周邊三峽景點子頁、登山資訊（白三山登山步道、白雞山-紫微天后宮步道，列表＋Popup）的內容模板；行脩宮僅為外部連結，不建站內頁面
- UI Flow／使用者情境流程圖

**這階段不做（列為未來擴充，不在本次規格內）：**
- 店家線上訂位／電商／金流
- 多語言版本（日後可擴充英文／日文，供外國遊客使用）
- 會員系統、評論評分系統
- App 化／PWA

## 5. 待確認事項清單（需向商場管理方 / 實地確認）

以下內容在規格中先以結構呈現，**實際數據待確認**，請勿直接採信文件中出現的範例數字：

- [ ] 商場正式營業時間、公休日
- [ ] 停車場車位數、是否收費、大型遊覽車停車動線
- [ ] 廁所確切位置與數量（含親子廁所、無障礙廁所）
- [ ] 行脩宮官網連結（https://www.ht.org.tw/）是否為最新正確網址
- [ ] 白三山登山步道、白雞山-紫微天后宮步道的正式名稱、里程、高度落差、預估時間、難度分級、入口座標
- [ ] 建議收錄的「周邊三峽景點」清單（如三峽老街、祖師廟、鳶山等）與其與商場的實際距離/車程
- [ ] 商場店家初始名單與分類

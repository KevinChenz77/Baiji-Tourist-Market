# 規格內容

三峽白雞觀光商場官網的內容規格文件。依閱讀順序：

1. [01-網站總覽與目標](01-網站總覽與目標.md) — 背景、受眾、範圍、待確認事項
2. [02-網站架構(Sitemap)](02-網站架構(Sitemap).md) — 全站架構圖、路由對照表、導覽設計
3. [03-頁面內容規格](03-頁面內容規格.md) — 逐頁的版面區塊、內容欄位、資料需求
4. [04-UI-Flow與使用者情境](04-UI-Flow與使用者情境.md) — 四種使用者情境的操作流程圖、UX 原則
5. [05-後台管理系統規格](05-後台管理系統規格.md) — 上稿後台技術選型（Strapi／SQLite／Railway／Cloudflare）、帳號權限管理決策

視覺化版本（含架構圖與流程圖的 Artifact）另外發佈於對話中，可直接分享給團隊或商場管理方確認內容。

**目前狀態**：網站架構（Sitemap、導覽結構、頁面互動模式：頁籤／獨立詳情頁／外部連結／首頁三區塊）已確認，定版於 v0.4。首頁三區塊（輪播圖／最新訊息／店家工商廣告）的資料結構（改為寫在首頁元件 `.ts` 檔案內的常數陣列，非外部 JSON）與輪播套件選型，交通方式頁的 Google Map 顯示方式、大眾運輸五種搭乘組合（公車／免費公車／捷運＋公車／捷運＋免費公車／新店捷運站＋免費公車），商場介紹頁拆出獨立子頁 `/market/about`（商場簡介與沿革），商場店家頁 `/shop` 的分類篩選（全部／餐飲／小吃／品茶／農特產／命理／服務，PC 按鈕／Mobile 下拉、querystring `type` 同步、隨機排序）與店家資料結構（分類 enum＋店家陣列，2026-10-05 起改放共用的 `shop.service.ts`，供列表頁與新增的 `/shop/detail/:number` 獨立詳情頁共用，原規劃的 Popup／Modal 詳情已汰換；同日決定 `phone` 聯絡電話在列表卡片與詳情頁都顯示，`:number` 查無對應店家時導回 `/shop` 列表頁、不另做 404 頁面），周邊三峽景點頁 `/nearby/sanxia-attractions` 的景點卡片版面（PC 5欄／Mobile 2欄、依車程遠近排序、導航＋外部連結雙按鈕）與景點資料結構（同樣寫在頁面 `.ts` 檔案內，含範例景點與座標），以及登山資訊頁 `/hiking` 改為卡片列表（PC 4欄／Mobile 2欄，移除原本的 Popup 互動，卡片點擊直接新分頁開啟健行筆記等外部來源網站）與步道資料結構（含白雞山登山步道、紫微聖母環山步道兩筆真實資料），已於 [03-頁面內容規格](03-頁面內容規格.md) 與 [02-網站架構(Sitemap)](02-網站架構(Sitemap).md) 補上細節。商場簡介與沿革頁 `/market/about` 的沿革文案（原為依公開資料推論的草稿）2026-10-05 決定不採用猜測內容，改為頁面留空版位待商場管理方提供正式文案。其餘頁面內部的詳細內容（文案、版型細節）將另開新 session 討論。
